# Product

## Register

product

## Platform

android

## Users

购买 AI 主机的用户。他们通常在手机上完成主机激活，并把手机作为访问自己主机和 Agent 的主要入口。

## Product Purpose

ClawPi 是 AI 主机的配套 Android 客户端。用户登录并绑定主机后，可以通过手机与主机内的 Pi agent 对话。第一版成功标准是用户能完成登录、设备绑定，并稳定进入聊天。

## Positioning

这是用户访问和管理自己 AI 主机的官方入口，聊天是第一项核心能力。

## Brand Personality

当前实现按专业、可靠、克制处理，后续可根据硬件品牌进一步调整。

## Anti-references

避免做成带有营销式大卡片、装饰性渐变和复杂侧边栏的通用 SaaS 控制台。

## Design Principles

- 先确认用户拥有哪台主机，再进入 Agent 能力。
- 让连接状态和设备归属始终清楚可见。
- 聊天是高频工作面，信息密度适中，操作路径短。
- 真实 Agent 接入前，演示状态也要明确标注，不伪装成已连接的生产服务。

## Accessibility & Inclusion

遵循 Android 基础可访问性：可读字号、足够的触控区域、清晰的错误反馈和不依赖颜色 alone 的状态表达。
